# 类型系统纪律

让编译器拒绝不可能的状态、混用的基本类型、以及未处理的分支。

- **给语义基本类型打品牌。** 两个参数共享同一个基本类型却含义不同，就给各自一个类型。在创建处校验一次。
- **外部数据在被 parse 之前是无类型的。** JSON、RPC 载荷、CLI 参数、配置、环境变量、数据库行，都在边界经过一个 parse 函数，由它返回带类型的模型。
- **从权威 schema 推导类型。** 当某个 schema 文件拥有一个形状时，从它推导类型，而不是手搓一个平行的。

TypeScript 语法见 **typescript-best-practices** 技能。
