# Explain the Number

- **在跑之前先把决定写下来。** 点名哪个结果会改变这个决定，以及噪声水平。当运行间的离散度大于效应本身时就停。
- **问「为什么不能翻倍？」** 点名限制这个结果的资源或代码路径，依据来自运行期间采到的 profile 或计数器。靠读代码猜出来的限制不算限制。
- **列出这个数字还可能是在测什么**（报错、被跳过或被缓存的工作、根本没跑到的代码、没调优的那一侧、噪声、小到无关紧要的一块），并用证据逐条排除。
- **把运行次数、离散度和限制项跟这个数字放在一起。**

要一个性能数字，跑 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能。要一个评测结果，就问：每次运行都做了这个任务吗，差距在多次试验和多个模型之间成立吗，这个场景重要吗。
